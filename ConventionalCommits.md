## 🔥 Os Mais Utilizados no Dia a Dia

- feat: Uma nova funcionalidade (feature) sendo adicionada ao sistema.
- fix: A correção de um bug ou erro no código.
- docs: Alterações exclusivamente na documentação (como o arquivo README.md ou comentários do código).
- refactor: Uma alteração no código que não corrige um bug nem adiciona uma funcionalidade (ex: melhorar a legibilidade ou performance do código).


## ⚙️ Utilitários e Estruturais

- test: Adição ou modificação de testes existentes (unitários, integração, etc.).
- chore: Atualizações de tarefas de build, configurações de ferramentas ou pacotes adicionados que não mexem no código de produção diretamente.
- style: Alterações que não afetam o significado do código (espaços em branco, formatação, ponto e vírgula faltando, linting). Não confunda com CSS/estilo visual.


## 🚀 Menos Frequentes / Avançados

- ci: Mudanças nos arquivos de configuração e scripts de Integração Contínua (ex: GitHub Actions, Jenkins).

- perf: Uma mudança de código focada exclusivamente em melhorar o desempenho.

- build: Alterações que afetam o sistema de build ou dependências externas (ex: Maven, Gradle, npm).

- revert: Utilizado para reverter um commit anterior.
